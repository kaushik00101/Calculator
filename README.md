# Calculator

A sleek, modern, and fully responsive web-based calculator built entirely from scratch using vanilla frontend technologies. This project features a clean user interface and real-time expression parsing, providing a smooth and intuitive user experience across all devices.

🌐 **[Live Demo Available Here](https://kaushik00101.github.io/Calculator/)**

---

## ✨ Features

*   **Core Arithmetic Operations:** Smoothly handles addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
*   **Grid-Based UI Layout:** Features a clean, intuitive button grid separating numbers, operational symbols, and structural action keys.
*   **Granular Correction (`del`):** Features an instant backspace function to remove the last entered digit or operator without wiping out your entire calculation.
*   **Floating-Point Math:** Supports accurate decimal input handling for fractional computations.
*   **Fully Responsive & Mobile-Friendly:** Designed with a mobile-first mindset, ensuring the calculator scales perfectly on mobile screens, tablets, and desktop displays.

---

## 🛠️ Tech Stack

*   **HTML5:** Structure and semantic layout of the calculator display and interactive buttons.
*   **CSS3:** Clean styling, responsive flexbox/grid alignments, and smooth hover/active state transitions for buttons.
*   **JavaScript (ES6):** Dynamic event handling, real-time input tracking, and formula evaluation logic.
